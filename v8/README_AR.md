# STEEL DESIGN ERP V8 — مرحلة التطبيق الأولية

واجهة تشغيلية مستقلة في V8 مبنية على IndexedDB المحلية، مع الاحتفاظ بمصدر V7.11 دون تعديله.

## المنجز في هذه المرحلة
- تسجيل الزبائن والطلبيات.
- حفظ التطبيق والمسودة محلياً في IndexedDB.
- ترحيل محافظ لمفاتيح V7.11 المعروفة دون حذف LocalStorage القديم.
- حساب تاريخ التسليم تلقائياً من تاريخ الاستلام ومدة الإنجاز.
- متابعة حالات الإنتاج: جديد، قيد التصنيع، جاهز، مكتمل.
- طباعة أمر تصنيع OF منفصل بلا أسعار.
- طباعة BON CLIENT منفصل يتضمن سعر القطعة والخام والنقل والمدفوع والباقي.
- كروكي يدوي بالقلم أو اللمس.
- تصدير واستيراد نسخة احتياطية JSON.
- تخزين ملفات الواجهة للعمل دون اتصال بعد أول تحميل عبر Service Worker.

## ما لم يكتمل بعد
- نقل المخزون وREC والموارد البشرية والموردين والكتالوغ ومصمم المصعد من V7.11.
- ربط مباشر بطابعة حرارية أو طابعة لصاقات؛ الطباعة الحالية عبر نافذة طباعة النظام.
- تزامن أجهزة المكتب واللوح عبر الشبكة المحلية.
- اختبار Android فعلي وبناء APK مؤكد.

Capacitor يستخدم المجلد v8/www. سير GitHub Actions يعمل على فرع v8-real-app أو يدوياً.
